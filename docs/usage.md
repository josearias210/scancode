# Using ScanCode

ScanCode is a noncommercial Android project that runs without ads. Use **Enable camera** for live scanning or **Photo** to pick an image. ScanCode reads the code on your device.

## Review a web link

The result shows the destination host and any explicit port above the original code. Check the host before choosing **Open link**. The review distinguishes HTTP and HTTPS and highlights recognized shorteners, IP addresses, and internationalized domains written in ASCII.

The review reads the URL locally and leaves its reputation unchecked. For a shortened URL, it displays the shortener's host. Your Android browser or handler takes over when you choose **Open link**.

## Save and organize scans

Choose **Save** on a scan result to keep it in **History**. Recent history keeps up to 200 unique values. From **History** you can search saved codes, reopen them, delete individual entries, or clear the list.

To keep related codes together:

1. Choose **Add to collections** on any result. Create your first collection or select one or more existing collections.
2. To browse your groups, open **History** and choose **Collections**. Select a group or choose **New collection** to make an empty group.
3. To change a code's membership, reopen the result, choose **Collections**, and update the selections.
4. To rename or delete a group, open it and choose **Manage collection**.

Adding a new scan to a collection also saves it to history. Collection entries survive the history limit and **Clear all**. Deleting a collection leaves any copies in history or in other collections.
