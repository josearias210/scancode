# ScanCode instructions

- Keep repository documentation in English. Follow [CONTRIBUTING.md](CONTRIBUTING.md) for test coverage and pull request evidence.
- Use Docker Desktop for local Android builds and emulator tests on Windows. Use Docker for additional tools.
- Derive test cases from the requested behavior, existing tests, and known regressions. Add or update a test when existing coverage misses the changed behavior.
- For a visual change, exercise the affected screen and capture the result from the emulator or a test device. Include that evidence in the pull request. The automatic home screen capture covers app startup.
- Report which checks ran and their outcomes. Keep generated reports, screenshots, and signing material outside the tracked source tree.
