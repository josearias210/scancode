# Changelog

## 1.1.0 (unreleased)

- Redesigned the live viewfinder, scan details, saved history, and launcher icon.
- Added three viewfinder shapes, tap-to-focus, camera permission recovery, and photo-only use when the camera is unavailable.
- Added multiple-code selection for photos, content-aware actions, and separate Wi-Fi password copying.
- Added searchable history and confirmations for deletion. Existing saved codes remain readable.
- Added local link review with the destination, protocol, and indicators for shortened URLs, IP addresses, and internationalized domains.
- Added named collections that can retain saved scans independently of recent history.
- Added an English interface, kept Spanish support, and added light and dark appearance.
- Updated the build for Android 16 and added Gradle Wrapper, Android CI, and Play Store preparation files.

## 1.0

- Initial camera and gallery scanner with zoom, torch, result actions, and locally saved history.
